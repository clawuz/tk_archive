## Required Fixes Before Approval

### CRITICAL: Fix Large File Warning Logic
**File:** src/components/dam/VideoPreview.jsx

**Current problematic code (lines 64-89):**
```javascript
useEffect(() => {
  if (!file) return;

  try {
    if (!canStream(file)) {
      setCanPreview(false);
      return;
    }

    if (isFileTooLarge(file.size)) {
      setError(`File too large (${getFileSize(file.size)}). Download to play locally.`);
      setCanPreview(false);  // ← BUG: Makes error unreachable
      return;
    }

    const url = getStreamUrl(file);
    setStreamUrl(url);
    setCanPreview(true);
    setError(null);
  } catch (err) {
    setError('Unable to preview this video');
    console.error('VideoPreview error:', err);
  }
}, [file]);

if (!canPreview) return null;  // ← Exits before error can display
```

**Suggested fix:**
```javascript
if (isFileTooLarge(file.size)) {
  setError(`File too large (${getFileSize(file.size)}). Download to play locally.`);
  setCanPreview(false);
  setStreamUrl(null);
  return;  // Remove after return so error state persists
}
```

Then change the return condition:
```javascript
if (!file || (!canPreview && !error)) return null;
```

Or restructure the entire render logic to handle error state independently.
